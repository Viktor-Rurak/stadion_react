# Стадіон Дубівці — сайт спорткомплексу

Сайт із записом на універсальний корт, новинами, лічильником людей на полі
та трансляцією. Написаний на React, дані зберігаються в Supabase.

## Як запустити

Потрібен [Node.js](https://nodejs.org) (LTS-версія). У цій папці:

```bash
npm install     # один раз: завантажити залежності
npm run dev     # запустити сайт — адресу покаже в терміналі (зазвичай http://localhost:5173)
```

Зібрати версію для публікації — `npm run build`, результат з'явиться в папці `dist`.

## З чого складається проєкт

Три окремі частини, які спілкуються лише через базу даних:

```
┌─────────────────┐      ┌──────────────────────┐      ┌────────────────────┐
│  САЙТ (src/)    │◄────►│  SUPABASE (хмара)    │◄─────│  КАМЕРА            │
│  React у        │      │  база, акаунти,      │      │  camera-counter/   │
│  браузері       │      │  пошта, фото новин   │      │  camera-stream/    │
└─────────────────┘      └──────────────────────┘      └────────────────────┘
   те, що бачить            де все зберігається          програми для
   відвідувач               і хто що може                комп'ютера/сервера
```

## Карта папок

```
site-react/
├── index.html            оболонка сторінки: заголовок, іконка, картка для месенджерів
├── package.json          список залежностей і команд (npm run dev / build)
├── vite.config.js        налаштування збирача Vite
├── public/               файли, які віддаються як є: іконка та картинки плану
│
├── src/                  ── САЙТ ──
│   ├── main.jsx          точка входу: звідси все починається
│   ├── App.jsx           карта сайту: яка адреса → яка сторінка
│   ├── pages/            сторінки — один файл на одну адресу
│   ├── components/       частини сторінок, розкладені за призначенням
│   │   ├── layout/       каркас: шапка, підвал
│   │   ├── auth/         вікно реєстрації та входу
│   │   ├── home/         головна: план, картки майданчиків, «Як це працює»
│   │   ├── booking/      запис на корт
│   │   ├── news/         новини
│   │   └── field/        сторінка майданчика: лічильник, плеєр
│   ├── lib/              усе спілкування з базою даних
│   ├── data/             тексти й описи — окремо від розмітки
│   └── styles/           вигляд: кольори, кнопки, сторінки
│
├── supabase/             ── ТЕ, ЩО ЖИВЕ В SUPABASE (копії для читання) ──
│   ├── functions/        серверні функції: вхід за логіном, скасування реєстрації
│   └── email-templates/  українські шаблони листів
│
├── camera-counter/       ── програма, що рахує людей на полі (Python) ──
├── camera-stream/        ── трансляція з камери в YouTube (сервер) ──
└── docs/                 ── пояснення, як усе влаштовано ──
```

## Де що змінити

| Хочу змінити… | Іду у файл |
|---|---|
| текст інструкції «Як це працює» | `src/data/about.js` |
| назву чи опис майданчика | `src/data/objects.js` |
| адресу, пошту в підвалі | `src/components/layout/Footer.jsx` |
| пункти меню в шапці | `src/components/layout/Header.jsx` |
| колір сайту, шрифт | `src/styles/tokens.css` |
| вигляд кнопок, полів, сповіщень | `src/styles/ui.css` |
| назву сайту у вкладці, опис для месенджерів | `index.html` |
| види спорту, тривалість гри, години запису | `src/lib/bookings.js` (і правила в базі — див. docs/4) |
| текст листів | `supabase/email-templates/` (потім вставити в панель Supabase) |
| додати нову сторінку | створити файл у `src/pages/` і рядок у `src/App.jsx` |

## Головні правила проєкту

- **Усі обмеження живуть у базі, а не в браузері.** Код сайту можна підмінити
  в браузері, тому сайт лише *показує* правила, а *стереже* їх база: вона не
  пропустить запис довший за 2 години, навіть якщо надіслати запит в обхід сайту.
- **Тексти окремо від розмітки.** Щоб поправити текст, не треба розбиратися
  в коді — він лежить у `src/data/`.
- **Вигляд окремо від логіки.** Компоненти лише називають класи (`className`),
  а як ці класи виглядають — описано в `src/styles/`.
- **Секрети не потрапляють у git.** Паролі від камери й ключі лежать у файлах
  `config.env` і `stream.env`, які перелічені в `.gitignore`.
