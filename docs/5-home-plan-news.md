# 5. Головна, план і новини

## Головна сторінка

`pages/HomePage.jsx` складається з трьох частин, кожна — окремий компонент
у `components/home/`:

| Частина | Файл | Звідки бере тексти |
|---|---|---|
| інтерактивний план | `PlanMap.jsx` | `data/objects.js` |
| картки майданчиків | `ObjectsSection.jsx` | `data/objects.js` |
| інструкція «Як це працює» | `AboutSection.jsx` | `data/about.js` |

### Посилання в меню

Пункти «Об'єкти», «Як це працює», «Контакти» ведуть не на окремі сторінки,
а на місце на головній: `/#objects`, `/#about`, `/#contacts`. Частина після
`#` — це `id` елемента, до якого треба прокрутити. `HomePage` сама це робить:

```jsx
useEffect(() => {
  const id = hash.slice(1);
  if (!/^[\w-]+$/.test(id)) return;
  document.getElementById(id)?.scrollIntoView({ behavior: 'smooth' });
}, [hash, key]);
```

Перевірка `/^[\w-]+$/` не зайва: після переходу з листа адреса може
закінчуватися на щось на кшталт `#access_token=…`, і без неї сторінка
намагалася б знайти елемент із такою назвою.

## Майданчики (`data/objects.js`)

Усе, що сайт знає про майданчик, лежить в одному записі:

```js
{
  key: 'court',                    // коротка назва для коду
  id: 'obj-court',                 // id картки на сторінці
  name: 'Універсальний корт',
  description: 'Теніс, баскетбол і волейбол…',
  overlayImage: '/images/obj-court.png',       // вирізаний силует для плану
  labelSubtitle: 'Теніс · баскетбол · волейбол',
  labelPosition: { left: '23%', top: '64%' },  // де на плані стоїть підпис
  bookable: true,                  // на нього можна записатися
  labelAction: 'Натисніть, щоб записатися',
}
```

Поведінку визначають прапорці:

| Прапорець | Що дає |
|---|---|
| `bookable: true` | клік на плані й кнопка в картці ведуть на `/booking` |
| `link: '/news'` + `linkText` | клік і кнопка ведуть на вказану сторінку |
| `hasCounter: true` | у картці й на сторінці поля показується лічильник людей |
| `hasStream: true` | на сторінці поля показується плеєр трансляції |

Змінити назву чи опис — поправити рядок тут. Більше нічого чіпати не треба.

## Інтерактивний план (`components/home/PlanMap.jsx`)

План — це картинка, на якій майданчики підсвічуються під курсором. Складність
у тому, що майданчики не прямокутні й намальовані під кутом, тож звичайними
«зонами» їх не описати.

### Як сайт розуміє, над чим курсор

Для кожного майданчика заздалегідь збережено його **маску** — малесеньку
чорно-білу картинку 209 × 118 точок, де 1 означає «тут майданчик», а 0 —
«тут ні». Маски лежать у `data/planMasks.js` у стислому вигляді.

Коли курсор рухається:

1. беремо його координати на екрані;
2. переводимо в координати маски (ділимо на розмір плану, множимо на 209 × 118);
3. дивимось, чи стоїть у цій точці маски одиниця.

```js
const x = Math.floor(((event.clientX - rect.left) / rect.width) * MASK_WIDTH);
const y = Math.floor(((event.clientY - rect.top) / rect.height) * MASK_HEIGHT);
for (const key of HIT_TEST_ORDER) {
  if (maskHasPoint(masks[key], x, y)) return key;
}
```

`HIT_TEST_ORDER` — порядок перевірки: менші майданчики першими, щоб вони
«вигравали» там, де силуети торкаються.

### Як виникає підсвітка

Компонент не малює ефектів сам. Він лише записує знайдений майданчик в
атрибут контейнера:

```jsx
<div className="plan-map" data-hover={hoveredKey ?? undefined}>
```

А далі все робить CSS (`styles/home.css`):

```css
/* коли щось підсвічено — весь план темніє */
.plan-map[data-hover] .plan-base { filter: brightness(0.52) saturate(0.55); }

/* а потрібний майданчик з'являється поверх і трохи підіймається */
.plan-map[data-hover="court"] .overlay-court {
  opacity: 1;
  transform: scale(1.055) translateY(-8px);
}
```

Поверх базової картинки лежать три вирізані PNG — по одному на майданчик.
Зазвичай вони прозорі; CSS показує потрібний.

### Миша й палець

На комп'ютері підсвітка йде за курсором. На телефоні курсора немає, тому:

- **торкнулися й тримаєте** — майданчик підсвічується, поки палець на екрані;
- **тримали довше 0,4 секунди й відпустили** — нічого не відбувається (людина
  лише роздивлялась);
- **короткий тап** — перехід, як клік мишею.

За це відповідають `handlePointerDown`, `handlePointerEnd` і таймер
`longPressTimer`.

### Куди веде клік

```js
if (object.bookable) navigate('/booking');
else if (object.link) navigate(object.link);
else if (object.hasCounter) navigate('/fields/' + object.key);
else navigate({ hash: '#' + object.id });
```

### Додати майданчик

1. запис у `data/objects.js`;
2. вирізаний PNG майданчика в `public/images/`;
3. маска в `data/planMasks.js` з тим самим `key`;
4. у `styles/home.css` — правила `.overlay-<key>` за зразком наявних;
5. додати `key` в `HIT_TEST_ORDER`.

Маски згенеровані з PNG-силуетів окремим скриптом, якого в проєкті немає.
Для нового майданчика маску доведеться згенерувати заново — це разова
робота для розробника.

## Сторінка майданчика (`pages/FieldPage.jsx`)

Одна сторінка на всі майданчики: адреса `/fields/train` означає «покажи
майданчик із `key: 'train'`». Сторінка знаходить його в `objects.js` і,
залежно від прапорців, показує плеєр трансляції, лічильник людей та опис.

## Новини

| Що | Де |
|---|---|
| сторінка для всіх | `pages/NewsPage.jsx` |
| адмінпанель | `pages/AdminNewsPage.jsx` |
| картка новини | `components/news/NewsCard.jsx` |
| форма (заголовок, текст, фото) | `components/news/NewsForm.jsx` |
| запити до бази й сховища | `lib/news.js` |

### Як зберігається новина з фото

Текст і фото лежать у різних місцях:

```
форма ──► фото ──► сховище Supabase (кошик news) ──► повертає посилання
      └─► заголовок, текст і ЦЕ ПОСИЛАННЯ ──► таблиця news
```

1. `uploadImage()` перевіряє, що це картинка до 5 МБ, дає їй випадкове ім'я
   (у назвах із телефона бувають пробіли й кирилиця) і кладе у сховище.
2. Сховище повертає публічне посилання.
3. `createNews()` записує в таблицю заголовок, текст і це посилання.

Коли фото замінюють або новину видаляють, старий файл теж прибирається зі
сховища — інакше там накопичувалося б сміття.

### Хто може писати

Адмінпанель перевіряє `isAdmin` і не показує форму іншим. Але це лише
зручність: справжній захист — політика в базі. Навіть якщо хтось обійде
сторінку й надішле запит сам, база відповість відмовою.

Тому в `AdminNewsPage` три стани на вході:

| Хто зайшов | Що бачить |
|---|---|
| гість | «Щоб потрапити сюди, увійдіть» |
| звичайний користувач | «Тільки для адміністраторів» |
| адмін | форму й список новин |

### Абзаци в тексті

Текст новини — звичайний текст, не HTML. Переноси рядків зберігаються
завдяки одному правилу CSS (`white-space: pre-line`), а будь-які теги, які
хтось уставить у текст, покажуться як літери й не спрацюють. Це захист від
того, щоб через новину на сайт потрапив чужий код.
